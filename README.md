# Typenhebel

Deutschsprachiger Tipptrainer: gemeinfreie Literatur abtippen, Tippverhalten auswerten. Läuft komplett im Browser, keine Datenübertragung.

```sh
npm install
npm run dev        # Entwicklungsserver
npm test           # Unit-Tests (Vitest)
npm run e2e        # E2E- und Screenshot-Tests (Playwright)
npm run build      # Produktionsbuild nach dist/
```

Details: [SPEC.md](SPEC.md). Manuelle Tastatur-Prüfung: [docs/tastatur-checkliste.md](docs/tastatur-checkliste.md).
